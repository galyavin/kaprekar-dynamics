# Ancillary files: correction to Conjecture 10 (22 November 2026)

Evidence for the theorem in *Correction to Conjecture 10 of Macroscopic cycles in odd-length Kaprekar dynamics*:

- `settle35/`: the proof (`FAMILY.md`, `TRANSPORT.md`), the exact certificate (`family-certificate.json`), the verifier and literal-subtraction controls at three bases.
- `recon_settle35/`: an independent reconstruction from P10's definitions, with its own exact checker and literal controls at two further bases.
- `pinning_rank/`: exact certificates for c(n) at every eligible odd length below 10^4 (274 non-strict lengths with c = 0, 94 prime), used in the note's open question.

Each folder has its own README and SHA256SUMS. Release copies differ from the working copies only in that internal links point to released DOIs and the conjecture is named "Conjecture 10".
