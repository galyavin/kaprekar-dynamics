# Task 098 regular-closure return certificate

Freeze a 10-turn test, in descending stratum dimension and lexicographic
rotation order within dimension. Near a limit on the regular period-five
closure, use the folded rotating frame with one correction per active
weak comparison. Require all 11 full-turn sections to have a negative
active comparison and to have distinct projected comparison values.
Test feasibility over exact real linear arithmetic (Z3 and Yices).
The expectation is UNSAT on dimensions four through two. Dimension one
is a test, with no prediction. The apex and period-two/three families have
independent proofs to attempt and are outside this certificate.
